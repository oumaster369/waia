The full official font includes Latin and Cyrillic glyphs. Local asset inspection
confirmed all printable ASCII letters/punctuation, Russian А–я and Ё/ё. No font
outlines or metrics were edited, subsetted or converted.

Self-hosting avoids the build-time Google CSS query parser failure already
encountered by Cormorant Garamond in this repository. The family, CSS variable,
root/body class application and `display: swap` are preserved by next/font/local.
