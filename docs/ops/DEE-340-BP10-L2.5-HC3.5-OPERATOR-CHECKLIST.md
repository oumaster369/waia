## Step 1 — Prepare evidence and operator inputs

1. **Export production Evidence JSON** from U1 Postgres on the execution host (read-only):

```bash

DATABASE_URL_POSTGRES='<operator-vault-postgres-url>' \
pnpm trader:paper:export -- \
  --org-id='<ORG0_UUID>' \
  --window-start=2026-06-01T00:00:00.000Z \
  --window-end=2026-06-15T00:00:00.000Z \
  --strategy-signal-ids=mean_reversion_v0 \
```
