The fixed native decision operation has two intents: owner enrollment requests PROFILE, every otherwise-unprofiled covered write requests LEGACY. It performs `INSERT ... No no-op `DO UPDATE`, caller-supplied read function, GUC/session flag or arbitrary claimed owner token is used. - If the winner rolls back, the waiter can obtain its own mode normally; no persistent lock stealing or manual history repair.
