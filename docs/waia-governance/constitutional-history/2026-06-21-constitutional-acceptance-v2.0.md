# Constitutional Acceptance v2.0

## Status

**DOCTRINE — Accepted. Append-only constitutional artifact.**

- Binds **within the limits its own articles declare**. It does not authorize implementation, runtime, gates, or agent identities by its own existence.
- On conflict with the operational canon (`AGENTS.md`, `WAIA-DEV-OS.md`, `EXECUTION-CONTRACT.md`, and the governance corpus) or with the prior acceptance (`2026-05-10-constitutional-acceptance-v1.0.md`), the existing canon wins; this artifact is amended to reconcile.
- **"v2.0" denotes acceptance of WAIA Operations System v2.0** — it is **not** a successor index to Acceptance v1.0. The two acceptances form a **doctrine stack** with disjoint scopes (2026-05-10 = agent doctrine; 2026-06-21 = ecosystem integration). **Neither supersedes the other.**

## Context

This artifact records the formal acceptance of **WAIA Operations System v2.0** as the ecosystem-level constitution above the in-repo WAIA DEV OS (the Development subsystem), and the acceptance of **Governance Integration Phase 0** as defined in the Master Plan.

- **Relationship to prior constitutional acceptance:** The 2026-05-10 Acceptance v1.0 governs agent doctrine (Agent Society review, Gate model, charter prerequisites). This v2.0 acceptance governs ecosystem integration (Founders Council, Sources of Truth, Constitutional Intake). They coexist; the 2026-05-10 Gate model and Article 3 disciplines remain fully in force and are reaffirmed here.
- **Lineage:** This artifact is added append-only to `constitutional-history/`. Prior artifacts are not edited. The folder index and `CONSTITUTIONAL-DOCTRINE.md` are updated (as PR1 index deliverables) to present the doctrine stack.

## Constitutional Findings

These conclusions are already ratified (no new conclusions are introduced):

- WAIA DEV OS is the Development subsystem of the WAIA ecosystem and operates under Founders Council authority.
- The Founders Council is apex authority; the Human Architect is its execution delegate.
- English is the canonical documentation language, with a carve-out for verbatim product/UI copy and illustrative user-utterance examples.
- Knowledge is repository-first; no second knowledge base is adopted in Phase 0–1.
- Financial Sustainability First: AI-Twin v1 is the default primary product track; AI-Trader activation is a reserved allocation decision.
- Agents are advisory only; the Gate model is mandatory and sequential; Product Auditor is the first and only candidate; no agent is authorized and no gate is opened.
- Integration is additive-first; authority reconciliation is isolated to PR2.

## Doctrine Statement

**Now accepted:** the Founders Council authority layer; the Sources-of-Truth (Repository-First) knowledge layer; the Agent Charter control layer (Gate A doctrine); the English Canon Rule and carve-out; the Financial Sustainability First doctrine; the Constitutional Intake Procedure; and additive-first integration.

**Remains deferred:** opening Gate B (and C, D); authorization or activation of any agent identity (including Product Auditor); Linear structural expansion; Community, Financial, and Narrative operational surfaces; and all Founders-reserved decisions (roadmap/capital allocation, tokenomics, treasury, portfolio, new vendor surfaces).
